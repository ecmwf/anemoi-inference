#########################
 Configuration reference
#########################

The configuration reference lists every option of a run configuration,
including all runners, inputs, outputs and processors, with examples. It
is generated from the code, so it is the most complete and up-to-date
list of options.

If an option is marked "auto-generated", it has been directly created from the code.
If it is marked "AI written", it has been augmented using an AI agent. If
there is no flag, it has been validated by a human.

The reference also has a builder: use **Add to config** on any component
to assemble a configuration, check it against the documented options and
download it as ``config.yaml``.

`Open the configuration reference <../../config-reference/index.html>`_
